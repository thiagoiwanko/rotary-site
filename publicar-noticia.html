Publicar notícia no site

Página de uso interno — não é indexada e não aparece em nenhum menu do site. Só publica quem colar aqui um token válido do GitHub com permissão de escrita neste repositório. Não compartilhe o link nem o token desta página com ninguém de fora do clube.

1. A notícia

Vai aparecer igual nas versões em português, inglês e espanhol do site (sem tradução automática).
Se não enviar foto, o card da notícia usa uma imagem padrão do site.

2. Autorização de publicação

Como criar o token (só precisa fazer isso uma vez)
  1. Entre em github.com/settings/personal-access-tokens/new logado com a conta dona do repositório.
  2. Em "Repository access", escolha "Only select repositories" e selecione rotary-site.
  3. Em "Permissions" → "Repository permissions", mude Contents para Read and write.
  4. Defina uma data de expiração (ex.: 1 ano) e clique em "Generate token".
  5. Copie o token gerado (começa com github_pat_) e cole no campo acima. Guarde-o em local seguro — o GitHub só mostra uma vez.
